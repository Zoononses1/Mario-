# Pixel Hopper — لعبة منصّات للموبايل والكمبيوتر

لعبة بسيطة شبه ماريو: جري وقفز ودوس على الأعداء وجمع عملات، مراحل لا نهائية (كل مرحلة أصعب)، وبتشتغل **أوفلاين** بعد أول فتح. بتحفظ مرحلتك وأعلى نتيجة.

## الرفع على GitHub وتشغيلها على أندرويد

1. افتح github.com → **New repository** → سمّيه مثلاً `pixel-hopper` → خليه **Public** → Create.
2. اضغط **uploading an existing file** وارفع كل الملفات (من غير مجلد، الملفات نفسها):
   `index.html` `game.js` `manifest.json` `sw.js` `icon-192.png` `icon-512.png` `.nojekyll`
   ثم **Commit changes**.
3. من **Settings → Pages**: Source = **Deploy from a branch**، Branch = **main** و **/ (root)** → Save.
4. استنى دقيقة، ورابط اللعبة هيظهر بالشكل ده:
   `https://USERNAME.github.io/pixel-hopper/`
5. افتح الرابط في **Chrome على الأندرويد** → القائمة ⋮ → **Install app** (أو **Add to Home screen**).
   هتظهر أيقونة على الشاشة، وتفتح ملء الشاشة بوضع أفقي.

> لازم تفتحها مرة واحدة بالنت علشان تتحمّل، بعدها تشتغل في السفر من غير إنترنت.

## التحكم

**موبايل:** ◀ ▶ للحركة، **A** قفز (اضغط أطول = قفزة أعلى)، **B** جري (امسكه).
**كمبيوتر:** الأسهم أو WASD للحركة، Space قفز، Shift جري، P إيقاف، M صوت، F ملء الشاشة.

## نصايح اللعب
- الدوس على العدو من فوق بيقتله. الأشواك لازم تتفادى بالقفز.
- كتل `?` فيها عملات، وبعضها فيها **درع** (بيحميك من ضربة واحدة).
- علم الـ Checkpoint في نص المرحلة.
- زر ♪ بيبدّل: صامت / مؤثرات / مؤثرات + موسيقى.
- اللعبة بتتوقف لوحدها لما تطلع منها.

## تحديث اللعبة بعد الرفع
عدّل الملفات على GitHub، وغيّر رقم `CACHE` في `sw.js` (مثلاً `pixel-hopper-v2`) علشان الموبايل ياخد النسخة الجديدة.
